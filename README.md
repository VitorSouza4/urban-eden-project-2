  Urban Éden

Site educativo sobre plantas para iniciantes e arborização na Zona Leste de São Paulo.

  Objetivo

O Urban Éden busca incentivar o cultivo de plantas dentro de casa e conscientizar sobre a importância da arborização e os impactos do desmatamento na Zona Leste de São Paulo.

  Público-alvo

Moradores da Zona Leste de São Paulo que desejam começar a cultivar plantas em casa, mesmo com pouco espaço ou pouca experiência.

- HTML
- CSS
- JavaScript
